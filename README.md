# Лабораторна робота №2: політ дрона до заданої точки (Gazebo + ArduPilot SITL + ROS 2)

Варіант 25: dx = 4.6, dy = 1.1. Ціль: (x0 - 4.6, y0 - 1.1).

Політ виконується на висоті 4 м, бо у наданому світі maze.sdf пряма від старту (0; 0) до цілі
перетинає стіни Wall_7 і Wall_9 (їх верх 3.25 м).

## Результат польоту

| | x, м | y, м |
|---|---|---|
| Старт | 0.000 | 0.000 |
| Ціль | -4.600 | -1.100 |
| Перед посадкою | -4.541 | -1.082 |

Похибка досягнення цілі: 0.061 м.

## Структура

- `src/fpv_lab2` - ROS 2 пакет: `flight_test` (початковий приклад), `target_flight` (власний алгоритм польоту до точки)
- `scripts` - скрипти запуску, зупинки, збірки (`start_all.sh`, `start_sim.sh`, `run_flight.sh`, `stop_sim.sh`, `build.sh`)
- `report` - лог польоту, результат, карта лабіринту, версії ПЗ

## Запуск

Потрібні Ubuntu 22.04, ROS 2 Humble, Gazebo Harmonic і ArduPilot SITL у `~/ardu_ws`.
Збірка пакета: `scripts/build.sh`. Запуск усього: `scripts/start_all.sh`. Зупинка: `scripts/stop_sim.sh`.
